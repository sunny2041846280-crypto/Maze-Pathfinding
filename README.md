# 迷宫寻路算法可视化与对比 (Maze Pathfinding)

本项目为数据结构课程（栈与队列章节）的实践项目。项目**完全手写**了顺序栈与循环队列（无任何 STL 依赖），并分别利用这两种数据结构实现了 DFS（深度优先搜索）与 BFS（广度优先搜索），用于求解迷宫寻路问题。

## 🌟 核心功能与亮点

- **底层数据结构手写**：不依赖 `std::stack` 或 `std::queue`，纯手工实现顺序栈（Stack）与循环队列（Queue），深刻理解“后进先出”与“先进先出”的底层逻辑。
- **DFS 与 BFS 双算法对比**：直观展示两种搜索策略的差异。DFS 倾向于“一条路走到黑”，BFS 像“水波扩散”，保证第一次找到的路径必定是最短路径。
- **精准路径回溯**：使用额外的前驱数组（`prevR` 和 `prevC`）记录每个结点的来源，成功到达终点后，能够从终点精准回溯并绘制出最终路径。
- **八方向拓展（Bonus）**：支持四方向（上下左右）与八方向（增加四个斜向）的搜索扩展，验证算法在不同连通图模型下的正确性。
- **鲁棒性处理**：包含迷宫尺寸越界检查，以及无解迷宫的安全退出（输出“无解”），不会发生死循环或程序崩溃。

## 🛠️ 技术栈

- **语言**：C++ (C++11 及以上)
- **开发环境**：Dev C++
- **核心概念**：深度优先搜索 (DFS)、广度优先搜索 (BFS)、循环队列、前驱回溯算法

## 📁 项目结构

- `main.cpp`：主程序入口，处理文件读取、算法调度以及结果打印。
- `Maze.h`：迷宫数据的全局声明与基础工具函数（读文件、打印）。
- `Stack.h`：手写顺序栈类定义，包含 push、pop、top、empty 接口。
- `Queue.h`：手写循环队列类定义，包含 enqueue、dequeue、empty 接口（采用牺牲一个单元策略判满）。
- `maze.txt`：默认的 10x10 迷宫测试样例（可自行替换）。

## 🚀 如何运行

1. 将项目代码克隆到本地。
2. 确保 `maze.txt` 与编译生成的可执行文件（`.exe`）在同一目录下。
3. 使用 Dev C++ 打开 `MazePath.dev` 或直接编译 `main.cpp`，运行即可。

> **提示**：程序支持命令行参数指定迷宫文件，例如运行 `MazePath.exe test2.txt`。

## 📊 算法结果对比分析 (以默认 maze.txt 为例)

| 指标 | 栈 (DFS 深度优先) | 队列 (BFS 广度优先) |
| :--- | :--- | :--- |
| **路径长度** | 27 格 | 19 格 (最短) |
| **访问结点数** | 65 | 74 |
| **路径形态** | 反复曲折，沿墙绕行 | 平直、最短 |

### 为什么 BFS 保证最短？
BFS 使用队列，遵循“先进先出”原则。它像水波一样按“层”向外扩散。当 BFS 第一次碰到终点时，由于所有距离更近的结点都已经被处理过了，所以此时到达终点的步数必定是最少的。
而 DFS 使用栈，遵循“后进先出”，一条路走到黑。它找到的第一条路只是碰巧先走通的一条路，并不能保证全局最优。
