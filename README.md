# Maze-Pathfinding

中山大学数据结构第三章迷宫寻址project

\# 迷宫寻路算法可视化与对比 (Maze Pathfinding)



本项目为中山大学数据结构第三章 Project，纯手工实现了顺序栈与循环队列，并用其分别实现了 DFS（深度优先）与 BFS（广度优先）迷宫寻路。



\## 功能亮点

\- \*\*无 STL 依赖\*\*：完全手写 Stack 和 Queue 数据结构。

\- \*\*DFS 与 BFS 对比\*\*：直观展示不同数据结构带来的搜索路径差异。

\- \*\*八方向扩展\*\*：支持四方向与八方向（含斜走）的算法验证。

\- \*\*路径回溯\*\*：使用前驱数组实现最短路径的精准还原。



\## 如何运行

1\. 在本地编译 `.cpp` 文件。

2\. 确保 `maze.txt` 与可执行文件在同一目录下。

3\. 运行程序即可查看对比结果。
